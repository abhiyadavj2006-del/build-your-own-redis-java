Live Redis — in your browser LIVE

The same Redis from the Java server (about the Java version), re-implemented in pure JavaScript. It runs entirely in this page — no server, no network, no account. Type a command below and press Enter.

Your data stays in this browser. Keys are saved in localStorage, so they survive a reload — but only on this device and browser. FLUSHDB wipes them. The Java server adds streams, pub/sub and replication; this page adds the hashes and sets the Java tutorial leaves out.
